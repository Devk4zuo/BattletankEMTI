BATTLE TANK EMTI - MOVIMENTO MULTIPLAYER V1

OBJETIVO DESTA ETAPA
====================
Nesta versão, o movimento dos JOGADORES HUMANOS passa a ter o servidor FastAPI como autoridade.

Antes:
- cada navegador movimentava somente seu próprio jogador;
- os outros jogadores humanos não recebiam movimento real;
- a arena inicial era compartilhada, mas a batalha ainda era local.

Agora:
- o navegador envia apenas a intenção de movimento (WASD/setas);
- o FastAPI calcula a posição oficial;
- o servidor valida limites do mundo e obstáculos;
- o servidor valida colisão entre jogadores humanos;
- o servidor envia snapshots da posição para toda a sala;
- os outros alunos passam a ver os jogadores humanos se movimentando;
- o cliente mantém predição local para o controle não parecer pesado;
- o servidor corrige divergências de posição.

CONTROLE DO PROFESSOR
=====================
A Central do Professor agora possui o botão:

ENCERRAR PARTIDA

Ao confirmar:
- o servidor muda a sala para finished;
- todos os jogadores recebem match_ended;
- a batalha para para todos;
- aparece "PARTIDA ENCERRADA / ENCERRADA PELO PROFESSOR".

=======================

python -m uvicorn app.main:app --reload

2. Professor:
http://127.0.0.1:8000/host

3. Abra dois navegadores/janelas para alunos:
http://127.0.0.1:8000/

4. Entre os dois alunos na mesma sala.

5. Inicie preparação e depois batalha.

6. Mova o ALUNO 1 com WASD.

7. Faça o mesmo com o ALUNO 2.

8. Na tela do professor, clique ENCERRAR PARTIDA.
